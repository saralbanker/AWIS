# 07 — Indices (machine-navigable views over the corpus)
These files contain NO new information — every row is a pointer into canonical text. If an index
row and its target ever disagree, the target wins and the index row is a bug.

| File | Answers |
|---|---|
| `canonical-reference-map.md` | "Which document is authoritative for X, and at what tier?" |
| `traceability-matrix.md` | "Which milestone satisfies requirement family Y?" |
| `dependency-index.md` | "What must exist before milestone Z / what does it unblock?" |
| `cross-reference-index.md` | "Where is topic T specified across the corpus?" |
